# R12.8：列宽拖拽修复 + 一键更新（0.2.0）

## 一、列宽"拖不动 + 右侧大量留白"：两个真实缺陷

用户实测 0.1.9 反馈："又变成不能移动，而且栏目右边留有大量空白"。

| 现象 | 根因 | 修法 |
|---|---|---|
| 拖不动（拖动像被弹回） | 拖动回调里用**上一轮分配的快照**算 delta，并且**把被拖列又写回去**，每帧与系统拖拽打架 | 起点改为**手柄 DragStarted 时的真实宽度**；拖动中**只调整邻列**，仅在邻列触底时才夹回本列 |
| 右侧大量空白 | 任何列宽变化都被判定为"用户手动调过"→ `ManualGrids`，之后自动铺满**永久 return** | 只有**真实 DragStarted** 才进入手动模式；手动模式下列表变宽仍走 `SolveFill` 吸收差额，保证铺满 |

附带修掉一个时序坑：拖动瞬间 `ActualWidth` 可能还没更新，改用 `Width.Value`（原生拖拽写入的就是它）。

### 验证（`tools/ColumnProbe`，真实 WPF 窗口 + 真实手柄事件）

```
CanUserResizeColumns=True
gripperThumbs=8
before=[261.2, 261.2, 261.2] sum=783.6
after =[261.2, 301.2, 221.2] sum=783.6   ← 拖第二列 +40，第三列 −40
grew=40 shrank=40
[OK] 拖动生效：本列变宽、邻列等量变窄、总宽不变
[OK] 自动重排未覆盖用户调整
resized=[261.2, 301.2, 421.2] gridW=985.6 blank=2
[OK] 手动模式下变宽仍铺满（无右侧留白）
[PASS] column resize suite
```

主 UI 探针（真实主窗口四表，1220 宽）同时回归：右列空白 1.7~2px（= 边框）。

## 二、一键更新

### 之前为什么"点了没反应/不好用"

- 更新地址要用户自己填，普通用户不会填 → 点检查直接报"尚未配置地址"；
- 流程是两步（先"检查更新"再"下载并安装"）；
- 替换脚本依赖 `tasklist`（企业策略常禁用）。

### 现在

| 项 | 实现 |
|---|---|
| 更新地址 | **编译进程序集**（`csproj` 的 `UpdateFeedUrl`），用户无需填写；仍支持设置页/环境变量/exe 同目录 `latest.json` 覆盖 |
| 交互 | **一个按钮「检查并更新」**：检查 → 下载（带进度）→ 校验 SHA256 → 退出 → 替换 → 自动重启 |
| 替换 | 新 exe 先暂存到 `%LOCALAPPDATA%\DirPorter\updates\`，脚本**反复重试复制**（不依赖 tasklist）→ 启动新版本；目录不可写时提前返回并提示 |
| 校验 | 清单带 `sha256` 则强制比对，不一致直接判失败 |

优先级：设置页填写 > `DIRPORTER_UPDATE_URL` > 编译期常量 > exe 同目录 `latest.json`。

### 发布侧工具

- `tools/make-release.ps1`：算 SHA256、生成 `dist\<版本>\latest.json`、打印上传清单；
- `tools/sign.ps1`：代码签名（`DIRPORTER_PFX` 现成证书，或 `-SelfSigned` 自签名）；
- `installer/dirporter.iss`：Inno Setup 安装包脚本（开始菜单/卸载项/可选桌面图标），
  需要本机安装 Inno Setup 6 才能编译出 `setup.exe`。

### 生效前提（必须做的一步）

清单与 exe 必须能被终端用户匿名访问。当前内置地址为
`https://junmo.de5.net/dirporter/latest.json`，需要把

- `dist\0.2.0\latest.json` → `https://junmo.de5.net/dirporter/latest.json`
- `dist\0.2.0\dirporter.exe` → `https://junmo.de5.net/dirporter/0.2.0/dirporter.exe`

上传上去（两个地址浏览器直接能打开即可）。否则客户端点更新会报"检查更新失败 404"。

### 关于签名（如实说明）

- 脚本已就绪，但**没有证书无法做到"别人机器上不提示未知发布者"**；
- 自签名证书只在本机受信任，跨机器仍显示未知发布者，且不改变 SmartScreen 声誉；
- 想彻底消除必须买 OV/EV 代码签名证书（或云签名服务），把 pfx 路径给 `tools/sign.ps1` 即可。
- ⚠️ 签名会改变 exe 的 SHA256：**先签名、再跑 make-release.ps1**，否则清单里的摘要对不上。
