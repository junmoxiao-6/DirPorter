# R12.5 实施记录（0.1.7）

## 1. 迁移队列：单条删除

- `MigrateViewModel.RemoveFromQueueCommand(QueueItem)`：从队列移除（**执行中禁止**，避免与批次快照冲突）；
- 队列表新增「操作 / 移除」列；权重 `0,1,3,3,1,1,1,1`（8 列）。
- 「清空队列」保留（批量场景）。

## 2. 列宽“联动”问题

- 根因：手动拖动列分隔线 → DataGrid 按星号比例重排其余列（用户感知为“动一个全动”）。
- 修法：共享 DataGrid 样式 `CanUserResizeColumns="False"`——列宽统一由 `ElasticColumns` 计算。

## 3. `.migbak` 停车区管理（设置页）

**为什么会有 4 个**：`.migbak` 生成在**被迁移源目录的父级**下。迁移过
`C:\Users\31125\`、`AppData\Local`、`AppData\LocalLow`、`AppData\Roaming` 下的条目，
就会各自出现一个。**不是重复存储业务数据**：每个子目录是一次迁移的“源目录副本”（回滚兜底），
`.ledger` 是台账归档（长期保留）。

设置页新增卡片：
- 列表：路径 / 条目数 / 体积 / 最后写入时间；
- 操作：**打开**（资源管理器）、**删除**（二次确认；只删备份子目录，保留 `.ledger`）；
- 扫描范围：用户主目录、Local、Roaming、LocalLow 的 `.migbak` + 台账 `BackupPath` 推导出的其它盘位置。

## 4. 链接总览页（记录 ↔ 设置之间）

- 扫描范围可增删（默认用户主目录）；可选「包含硬链接」（逐文件检查，较慢）；
- 结果列：**链接所在路径 / 链接格式 / 目标（源目录）/ 状态（有效/悬空）/ 操作**；
- 链接格式四种如实标注：目录联接 (Junction)、目录符号链接、文件符号链接、硬链接；
- **还原**：复制目标内容 → 临时目录 → 删除链接本体 → 回填。目标目录保留；仅目录类链接可还原。

## 调试注记：ElasticColumns 的两个致命小错

1. **小数权重**（`0.7/0.9`）——解析器只接受整数 → 整串被丢 → 该表永远停在 ΣMin；
2. `total <= 0` 的提前 return 位于 `try` 外 → `Applying` 防重入标记未释放 → 该表此后永久被跳过。
最终策略：整数权重 + finally 释放 + 三拍重算（0/120/400ms）+ 布局变化兜底（200ms 冷却）。
