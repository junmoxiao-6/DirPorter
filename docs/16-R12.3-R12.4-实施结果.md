## 一、弹性列（代码驱动列宽）

**实现**：`src/DirPorter.App/Services/ElasticColumns.cs`

- 附加属性 `ElasticColumns.Enabled` + `StarWeights`（`0,4,1,1,1,2,1` 形式，0 = 固定列）；
- 按权重分配"表格可用宽"，clamp 到各列 `MinWidth`；
- **溢出处理**：clamp 造成的溢出从"高于 Min 的列按余量比例回缩"（不是整体放弃、也不是全部压 Min）；
- **重算时机**（关键）：主窗口 `Loaded` / `SizeChanged` / `CurrentPage` 变化 → `ApplyAll`；
  另在 PageHost 的 `LayoutUpdated` 上做 `SyncIfNeeded` 兜底（仅处理"宽度变了"的表格，收敛即停）。

### 调试中踩到的四个坑（都会导致"列压 Min + 右侧留白"）

| # | 坑 | 现象 | 修法 |
|---|---|---|---|
| 1 | 用 `grid.ActualWidth` 作基准 | 列宽↑ → 表格宽↑ → 正反馈，雪崩到 4000px | 父容器宽参与 + 取消 LayoutUpdated 上的无条件重算 |
| 2 | `delta ≈ 0` 被当作"空间不足" | 刚好铺满的一轮把全部列压回 Min | 区分 `delta < -0.5` |
| 3 | clamp 后溢出直接 `return` | 保留上一轮旧值（停在 MinWidth） | 按余量比例回缩 |
| 4 | 早期布局窗口宽不可信（≈0） | 按"窗口-226"裁剪 → 全列 Min 且定型 | **取消窗口宽裁剪**；重算改为纯事件驱动 |
| 5 | 页面重建后表格先 0 宽后有宽 | SizeChanged 漏轮次 | PageHost.LayoutUpdated → `SyncIfNeeded` |

### 验证（UiProbe 实测，空白 ≈2px = 边框）

| 档位 | scan | migrate | link | history |
|---|---|---|---|---|
| 1220×820 | 1022 / 1024 | 1005 / 1007 | 1022 / 1024 | **1022 / 1024** |
| 860×540 | 620 / 622 | 624 / 626 | 897 / 899 | 584 / 586 |
| 660×480（最小窗口） | 弹性列铺满，无表格级横滚 | 同 | 同 | 同 |

探针新增断言：1220 档逐页"右侧空白 ≤ 26px"、`ScrollableWidth == 0`、极端窄窗两端可达、拉宽后偏移归零。

## 二、占用报错加固（用户实测故障）

**证据**：`runs/` 三份 journal（11:23 / 11:28 / 11:33）均失败于源目录被占用——
`Roaming\Coze`、`Roaming\@deepseek-ai`，错误为 Win32 `32`（复制时文件被占用）与 `5`（源改名拒绝访问）。

**修法**：

1. `OCCUPANCY_SCAN` 检出占用即抛 `SourceOccupiedException`（**复制前拦截**），消息列出占用进程并给出两条出路（关闭程序 / 勾选「结束占用进程」）；
2. 启用「结束占用进程」后**复检**，仍占用则同样报错并说明"已尝试结束"；
3. `PARKING` 改名失败时**复检占用**，把 `拒绝访问(5)` 翻译成"哪些程序还在用 + 怎么办"；
4. **一键迁移建链页补齐「结束占用进程」开关**（此前只有迁移页有）。

## 三、功能职责拆分

| 页面 | 名称 | 职责 |
|---|---|---|
| 一键迁移建链 | 原"一键迁移"改名 | 复制 + 校验 + **建链** 一步到位 |
| 迁移 | 纯迁移 | 删除建链类型选择；按钮改「开始迁移」；**完成后「去建链」**跳到链接页并预填 |
| 链接 | 纯建链 | 不变 |

引擎：`MigrationPlanEntry.CreateLink`（默认 true），false 时跳过 LINKING / LINK_VERIFY；
台账 `LinkType = None`；扫描页"已迁移"判定升级为「源是链接」**或**「源不存在 + 台账 done + 目标存在」。
