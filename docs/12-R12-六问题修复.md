# R12 六问题修复：迁移标记 · 功能拆分 · 窗口缩放 · 性能 · 文案

> 触发：用户第四轮反馈的六个问题。要求：先出方案、再实现、逐条说明处理方式与验证方法。
> 版本 0.1.3 ｜ 验证：全量测试全绿 + UiProbe 渲染断言（含窄窗档）+ 发布自检。

## 问题一：迁移并建链后「已迁移」仍显示"否"

**根因（双）**：
1. `ScanRow.MigratedText`（界面绑定的字符串）只在语言切换时重算——刷新函数只改了 `IsMigrated` 布尔值，文本永远停在旧值；
2. 从**迁移页/一键页**执行迁移后，扫描页没有任何刷新通知机制（跨页联动缺失，只有旧的"扫描页一键"路径会刷新）。

**处理**：
- `ScanRow` 增加 `OnIsMigratedChanged` 钩子：状态一变，显示文本**立即**同步；
- 迁移批次完成（任何入口）→ `MigrateViewModel.BatchFinished` 事件 → `MainViewModel` 接线 → 扫描页 `RefreshMigratedFlags(paths)` 重判磁盘状态。

**验证**：R8 端到端用例升级为"一键页真实迁移 → 断言行 `IsMigrated==true` **且** `MigratedText=="是"`"；R12 新增"状态变化即同步文本"用例。

## 问题二：三功能完全拆分 + 链接类型补充

**处理**：
- **新增独立页「一键迁移」（导航第一位、启动默认页）**：源目录列表（可多个、支持浏览/手动添加/移除）+ 目标根 + 建链类型 + 一键完成，结果就地回报。主功能定位：不需要先扫描、不经过队列。
- **扫描页精简为纯扫描分析**：移除一键横条；勾选 → "加入迁移队列"（保留在结果区，发送后自动跳迁移页）；行级按钮改为"加入队列"。
- **迁移页**：队列精细控制（唯一批量入口）；**链接页**：mklink 工具（补"选文件"按钮，见下）。
- **链接类型"四种全展示（标灰）"**（用户拍板）：迁移页/一键页/设置页的选择器统一由 `LinkKindOption.BuildMigrationSet()` 提供——目录联接、目录符号链接**可选**；文件符号链接、硬链接**置灰**并附悬停原因（"仅支持文件对象"）。默认仍为 **/J 目录联接**。
- **链接页补齐文件级支持**：`IUserInteraction.PickFile`（接口默认方法，测试桩零改动）+ `OpenFileDialog` 实现 + 目标路径旁"选文件…"按钮。

**验证**：R12（一键页默认页/空源拒绝/四种展示且文件级置灰/默认 /J/链接页选文件入口）；R10/R11 断言更新为新结构。

## 问题三：窗口缩放卡在固定值

**根因**：`MinWidth=1000 / MinHeight=700` 硬限制（防布局塌陷的历史方案）。

**处理**：内容区包 `ScrollViewer`（Auto 双向滚动）+ 内层 `PageHost` 最小尺寸 560×620 —— 窗口最小尺寸放宽到 **820×540**，再小出滚动条、绝不塌。
**验证**：UiProbe 新增 **shell-narrow 档（860×540）**：断言窗口实际缩到位 + 渲染图复核（无横条、全内容可见）。过程中还揪出一个隐藏陷阱：`TextWrapping="Wrap"` 的说明长文在滚动容器（无限宽测量）下仍按单行撑宽（期望 627px → 触发横向滚动），加 `MaxWidth` 后 PageHost 从 688→618，横向滚动条消失。

## 问题四：点击任何操作都慢

**根因（4 个实锤热点）**：
| 热点 | 处理 |
|---|---|
| `TargetRoot` 每敲一键 → **同步写盘**（`File.WriteAllText`） | `UiDebouncer` 防抖 500ms；执行前 Flush、退出时统一保存 |
| 迁移页每键还遍历重算全队列 TargetPath | 并入同一防抖回调 |
| 链接页每键触发**文件系统探测风暴**（4 provider × 卷/目录 IO） | 评估防抖 300ms |
| 启动时读台账 ×2 + 每记录 ×2 轮重解析点探测（全在 UI 线程构造期） | 记录页/链接页改 **懒加载**（首次进入才加载，`EnsureLoaded` 幂等） |

**验证**：R12（防抖器合并/Flush 语义、懒加载构造时不加载）；UiProbe 全部页面照常渲染。

## 问题五：文案「不是链接」

`hist.health.notLink`：**"不是链接" → "未建链接"**（英文 "not a link" → "Not linked"）。两处调用点（记录页健康列、链接页删除提示）同时生效。
**验证**：R12 断言键值；本地化"中英非空"守护测试继续覆盖。

## 问题六：构建问题随时分析解决（常设）
