# v0.3.4

> 对比 v0.3.3。这一版专门修"更新走不完"——两个缺陷是实测暴露的（用户点「检查并更新」直接失败）。

## 对比 v0.3.3

### 修复

- **检查更新超时后只显示 .NET 原始文案**
  以前：`检查更新失败：The request was canceled due to the configured HttpClient.Timeout of 30 seconds elapsing.`
  现在：一句话说清「网络在 60 秒内没有响应（已自动重试，并尝试了 Release 清单与 GitHub API 两条通道）」，
  并给出下一步（检查网络/代理，或到 Release 页手动下载）。

- **下行通道的 30 秒总超时让下载必然失败**
  `HttpClient.Timeout` 覆盖"从发起到读完整个响应体"，而更新包约 65 MB。
  国内直连 GitHub 实测只有约 **21 KB/s**（2.5 MB 用了 120 秒），30 秒根本不可能下完——
  表现为"检查能过、点下载就失败"。

### 改进

- **检查更新更耐网络抖动**：超时放宽到 60 秒，`Release 清单` 与 `GitHub API` 两条通道各重试一次，
  任一成功即继续；全部失败才报错，并列出每条通道的失败原因。
- **下载改为断点续传**：先写 `.part`，中断后再次点击会用 `Range` 从断点继续，
  不再从头下 65 MB；总时限改为 45 分钟（按 20 KB/s 估算足够下完）。
- **下载进度显示速度**：`正在下载 37%（24.3 / 65.0 MB，0.9 MB/s）—— 中断后重试会从断点继续。`
- **下载完整性双保险**：先比字节数，再比清单里的 SHA256；不匹配自动删除临时文件。

### 新增

- Release 额外提供 **framework-dependent 版**（`dirporter-fd.exe`，约 **1.6 MB**，需已安装
  [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)）。
  这是给"网络太慢、65 MB 下不动"的情况准备的备选；功能与主版本完全一致。

## 安装

- 常规：下载 `dirporter.exe`（免安装，约 65 MB，无需运行时）。
- 网络差：下载 `dirporter-fd.exe`（1.6 MB）+ 安装 .NET 8 Desktop Runtime。

两个版本的 SHA256 都在 `latest.json`（主版本）与 Release 附件旁说明。
